# 管理界面使用

产品名为 VAVA Home。Web 以当前选择的基站为上下文，摄像头名称、配置、NAS 和任务均绑定该基站；切换基站会结束当前观看并处理未保存草稿。页面可在桌面和窄屏使用，提供浅色/深色主题。

概述和事件短片页面见 [界面截图](../README.md#界面截图)。

| 主导航 | 内容 |
| --- | --- |
| 概述 | 基站状态、摄像头封面、电量与工作状态、存储摘要 |
| 摄像头设置 | 名称、设备报告、图像、画质、工作模式、布防与计划等 |
| 事件短片 | 当前基站 TF / USB 片段；默认全部摄像头，可筛选 |
| 事件消息 | 检测、录像、配对、存储和系统事件及已读状态 |
| 基站设置 | 配对、本地存储策略、当前基站 NAS、时间、网络与诊断 |
| 操作记录 | 请求与持久任务结果，包括未知/失败状态 |
| 云存储 | Server 上实际上传的独立副本、上传资格和留存 |

## 概述与观看

基站名称位于摄像头面板标题，添加入口也在该标题处；最多四台。点击**封面**开始实时观看，名称不触发。卡片中的事件短片图标筛选当前摄像头，“设置”打开其配置。停止观看、画质、声音、全屏、抓图、对讲和本机录像见 [LIVE](LIVE.md)。

绿色在线圆点表示当前基站连接正常、摄像头已登记且至少一条当前连接有效；ALIVE 保活也算在线。下一行显示“已报告休眠”等工作状态。单有配对记录或旧报告不等于在线。

电池供电显示实际报告的百分比及报告时间。充电时电池填充仍按报告百分比，配闪电，下方显示“百分比 · 充电中”或“已充满”，不显示报告时间。未知电量不显示假定的 0% 或满电；不会为更新电量唤醒摄像头。

封面优先比较有效的最后观看帧和最近事件，只有新来源才替换；5 秒状态轮询保留已有图片节点。最后观看封面仅在本次浏览器内存保留，不写路由器 Flash。

## 配置与操作结果

保存意图、Agent 排队、发送、匹配回显和实际效果分别显示。冲突保留草稿，不默默覆盖另一个页面的修改；缺少报告时留空或显示未知。自定义工作模式才展开灵敏度、短片长度和再触发间隔。

配对在对话框显示准备、实际倒计时、成功或失败；取消成功自动关闭。不在顶部用一次性提示替代正在进行的任务。改名成功关闭弹窗。恢复与删除为两个不同操作，历史录像保留，详见 [摄像头控制](CAMERA_CONTROL.md)。

## 事件与存储

事件短片与云存储是两个目录。短片条目显示封面、摄像头名、可信时间、时长和检测类别；TF 首次回放可能显示调取进度。缓存播放不意味着云上传已开启；NAS 是每基站私有设置，不设成全平台统一“事件存储”。

事件消息页没有手机推送或邮件能力。对讲、恢复、云存储、NAS虽有后端和界面，仍有目标环境待验，具体见 [功能状态](FEATURES.md)。账户相关 API / 代码保留，但当前主导航没有账户菜单，不将隐藏代码视为已完成的用户管理流程。

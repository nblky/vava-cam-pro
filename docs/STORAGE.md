# 录像与存储

## 五种用途分开

| 用途 | 触发 | 保存位置与入口 |
| --- | --- | --- |
| 本机实时录像 | 观看者点击录像按钮 | 浏览器下载到观看设备；不归档到基站或 Server |
| 基站事件短片 | 摄像头 PIR / 检测触发 | 基站 TF / USB；管理平台“事件短片” |
| 云存储 | 录制开始时该摄像头云上传开关已启用 | 用户部署的 Server；“云存储” |
| NAS 备份 | 录制开始时该摄像头 NAS 开关已启用 | 当前基站的 NFS 目标；“基站设置 → NAS” |
| TF 回放缓存 / 封面预览 | 用户请求已有基站片段或封面 | Server 临时对象，分别标记 `tf_export` / `tf_preview`；不计为云上传 |

原厂历史录像导入为 `legacy_import` 独立来源。不存在通用的“Server 连续录像”业务；开发诊断的基站手动录像命令不等于 Web 本机录像。

## 基站目录、加密与索引

基站保存低功耗事件短片，主要目录为 `基站SN/YYYYMMDD/摄像头SN/HHMMSS_U_0`，另有两级 `vava.idx`。文件命名保持兼容的组织形式，密文和元数据由当前程序管理；不能将无后缀文件直接视为可播放的明文视频。不可信时间的片段保留标记，不伪造有效日期。

权威片段元数据与可重建目录索引配合使用；删除、自动留存和恢复会同步更新层级索引。当前摄像头名称不是文件身份，改名或移除配对不删除旧 SN 录像。

片段与 Server 文件可使用各自的加密密钥环；标准部署初始化密钥并启用加密。读出时认证解密，完整文件做 SHA-256 核对；缺钥或校验失败不降级成明文读取。密钥备份必须与片段分开保管。

删除采用持久 tombstone 和目录提交，正在读取的片段受租约保护。介质更换增加 storage generation，旧游标和旧任务不能静默读取另一张卡。文件元数据、索引恢复和真实设备断电可靠性是不同验证层级。

## 目录与封面

事件短片默认展示该基站全部摄像头，可按摄像头 SN 和时间筛选。每条展示摄像头名、可信时间、检测类别、时长与封面。标签支持 Movement、Human、Face 及组合；保留原始检测值，未知类型不猜成人脸。类别保存在片段元数据中，不依赖事件消息日志是否还存在。

封面从已有加密片段读取首个完整 I 帧的有限 TS 前缀，由 Server 生成 JPEG；不必调取完整短片，不唤醒摄像头。`tf_preview` 使用独立小任务队列，不挤满完整回放调取任务。观看结束的新帧或新事件才更新摄像头封面来源，普通电量/在线刷新不造成图片闪烁。

## 回放与传输

TF 列表按有界索引、游标、介质代次和时间过滤查询，不逐条上传视频。Web 先查来源匹配的有效缓存；没有缓存才创建可靠调取任务，完成后播放或下载。缺源明确报错，不自动换成云端对象。云存储页面只查询实际云对象，基站离线也可播放已有副本。

后台云上传可配置限速，主动 TF 调取不受该后台速率预算限制。控制、事件、媒体、文件有独立状态；传输仍受网络、认证、重组、磁盘和媒体适配耗时影响，不保证任意 1 MiB 对象“秒开”。路径 MTU 1200 字节不是文件大小或列表长度上限。

可靠文件通道使用 OFFER / DATA / COMMIT / ACK，支持协商批量传输、持久偏移、重复块冲突核对与断点续传。Server 完整校验并提交后才确认完成，基站随后保存收据。后台上传不得抢占所有控制或媒体资源。

## 云存储与 NAS 的策略

两个摄像头开关独立，默认关闭。录制开始时捕获资格与目的地；之后开启不追溯上传关闭期间的旧短片。关闭暂停合格任务，取消/重试/遗忘各有状态。更换 Server 身份或 NAS 目标后，旧任务显示 `destination_changed`，不会转发到新地址。

NAS 连接配置保存在**当前基站**的 `nas-config.bin`，与 Server 云目录无关。修改地址或导出路径前先停用并等待卸载。真实 Linux 挂载使用 NFSv3/TCP，需要目标内核、`mount.nfs`、正确权限及 UID 映射。普通目录测试 `--nas-lab-local` 不验证真实 NFS。

NAS 每片提交原编码 TS、轻量封装 MP4 及对应校验元数据；两份成功后才出完整收据，冲突目标不覆盖。MP4 封装有限制，不接受任意变参流/B 帧。目标目录为基站 ID / UTC 日期 / 摄像头 SN；时间无效进入 `unsynced`。NAS 备份不是独立 Web 录像浏览器。

## 留存与容量

基站本地留存、Server 云留存、TF 调取缓存期限彼此独立。基站生产策略默认启用，按日龄/容量压力清理，保护未完成云/NAS任务与读者；Server 云自动留存默认关闭；完整 TF 调取缓存保留约一小时。无效/回退时钟保守处理，不能保证一直有空闲空间。

Server 的云片段、调取、预览与导入共享真实物理配额和对象上限，不是每页各有一份容量。删除云对象不删除基站/NAS副本；删 TF 缓存不删除 TF 原片；移除摄像头也保留历史录像。

当前基站目录最多 65536 条元数据，Server 对象数最多 4096；同步日志、删除墓碑、队列均有容量限制，满额保守拒绝而非丢弃防重放记录。格式化、自动选择磁盘与安全弹出未提供完整接口。

云/NAS的业务代码与模拟测试已实现，真实远端云上传和真实 NFS 验收仍待完成；详见 [功能状态](FEATURES.md) 和 [验证](VALIDATION.md)。

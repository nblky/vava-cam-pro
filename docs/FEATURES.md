# 功能与验证状态

核对日期：2026-11-10。本表对应当前源码。**实现、自动测试和实机验收是三列独立状态**。自动测试使用模拟摄像头、回环网络或普通目录，不能证明原摄像头效果、真实 NFS、功耗或路由器长期稳定性。实机栏仅汇总已有 HomeWRK 验证记录，本次文档整理没有再次连接设备验收。

## 基站与管理平台

| 功能 | 当前实现 | 自动测试证据 | 实机验证与限制 |
| --- | --- | --- | --- |
| 专用 AP / 配对 | 临时 AP、120 秒窗口、正式网络下发、四槽登记；Web / LuCI 倒计时与取消 | `sdk-pairing`、`platform-retry-state`、`openwrt-mock`、`web-state` | HomeWRK 已完成原固件摄像头两阶段配对；四台同时配对、所有无线芯片及 AP reload 待验 |
| 摄像头名称 | 基站持久保存；SN / revision 防并发误改；Web、LuCI 可操作 | `sdk-control-config`、`web-state` | 软件链已验证；不向摄像头写名称，不更改历史录像身份 |
| 在线、休眠、电量 | 当前三路连接判断在线；电量、充电、报告时间来自摄像头上报 | `sdk-lowpower`、`web-state` | 已收到真实保活、休眠、电量和外接电源状态；电池校准与续航待验 |
| 唤醒与释放观看 | 按需唤醒；退出释放租约；空闲恢复休眠 | `link-recovery-state`、`sdk-lowpower`、`sdk-live` | 真实唤醒、观看后休眠及服务重启后的连接恢复有记录；长期功耗待验 |
| 工作模式 / 布防 / 周计划 | 持久配置、统一灵敏度来源、每周计划、独立启停 | `settings-state`、`desired-state`、`sdk-control-config` | 不是仅有菜单；已实现控制链。三种模式的真实触发、时长、间隔及计划到点效果未逐项验收 |
| 实时音视频 | Agent 收 H.264 / AAC；自有 UDP 到 Server；浏览器播放 | `sdk-live`、`sdk-live-duration`、`sdk-web-media` | 两台真实摄像头 1080P H.264 / AAC 解码通过；数小时、复杂弱网与多浏览器待验 |
| 手动 / 自动画质 | 三档、实际尺寸确认、自动升降档；连续切档有固件门控 | `h264-state`、`continuous-mux`、`sdk-continuous-live`、`web-state` | 实测三档与连续六方向切换；连续切档默认关闭，适用固件及限制见 [实时观看](LIVE.md) |
| 抓图 / 本机录像 | 当前观看帧抓图；用户点击后录制，下载到观看设备 | `sdk-web-media`、`web-state` | 真实抓图及 H.264 / AAC 本机 MP4 录制、解码有记录；不同浏览器下载行为待验 |
| 对讲 | 浏览器采音、AAC 下行、租约与权限校验 | `sdk-live`、`sdk-web-media`、`web-state` | 软件通道已实现；真实摄像头扬声器发声与回声效果未验收，依赖浏览器编码能力 |
| 基站事件短片 | PIR / 检测确认、有限时长、加密、目录、索引、回放与删除 | `sdk-clips`、`sdk-archive`、`sdk-archive-encryption`、`record-index-state` | 真实 PIR 短片加密落盘、解密、完整音视频与既有片段回放有记录；当前版本断电/拔盘/满盘压力待验 |
| 事件分类 / 封面 | Movement / Human / Face 类别随短片保存；已有录像 I 帧预览 | `sdk-clips`、`sdk-archive`、`sdk-exports`、`web-state` | 真实短片 JPEG 与事件列表可读取；全部人形/人脸触发分类尚无逐类实机验收 |
| 云存储 | 摄像头独立开关、可靠上传、续传、服务端加密、目录和留存 | `sdk-uploads`、`sdk-encryption`、`sdk-retention`、`file-store-state` | **后端与 UI 已实现，真实 HomeWRK 到远端存储的完整验收未完成**；TF 调取成功不能当成云上传通过 |
| 基站 NAS | 每基站 NFS 配置，独立摄像头备份开关、任务、TS + MP4 | `sdk-nas`（普通目录模拟） | **后端与 UI 已实现，真实 NFS 挂载、UID 映射、断网和备份均待验**；模拟目录通过不等于 NFS 通过 |
| 恢复摄像头 / 删除摄像头 | 两个独立操作、持久进度与确认；保留历史录像 | `sdk-removal`、`web-state` | **软件已实现，真实摄像头恢复结果和清除配对效果未验收**；不会只删一条登记冒充成功 |
| 自有账户 / ACL / 会话 | 三类角色、基站授权、凭据撤销、任务去重与审计 | `sdk-web`、`sdk-credentials`、`sdk-integration`、`web-state` | 登录、真实设备控制、未授权访问拒绝有记录；不是完整安全认证或第三方渗透报告 |
| 原厂加密录像导入 | 只读导入独立来源，不混入云存储 | `sdk-legacy-import` | 已有样本音视频/时间轴验证；不代表支持所有原厂版本和任意录像格式 |
| OpenWrt Agent / LuCI | 源码包、UCI / procd、状态、配对、改名、恢复、删除 | `openwrt-mock`、`web-state`、`agent-transport-check` | HomeWRK 手工部署可用；正式目标 SDK 安装包与升级流程未完成验收 |
| Server 部署 | 原生 Linux / NAS、systemd、Docker / Compose、OpenWrt 模板 | `deployment`、`maintenance-tools`、`openwrt-mock` | 本机 Server 与 HomeWRK 联调有记录；**Docker Server 镜像、目标 NAS 和 OpenWrt Server 安装包未验收** |
